# Privacidad.news — Prototipo

Prototipo estático del sitio de noticias **Privacidad.news**.

## Objetivo

- Diseño oscuro coherente con [privacidad.me](https://privacidad.me) y [boringprivacy.io](https://boringprivacy.io).
- Cabecera con logo `Privacidad / news` y buscador.
- Listado de noticias (contenido de ejemplo ampliado a partir del estilo del canal de Telegram).
- Panel lateral derecho con servicios recomendados (estilo similar al de Dontorrent, adaptado a privacidad).

## Cómo verlo

1. Activa **GitHub Pages** en este repositorio:
   - Settings → Pages → Source: Deploy from a branch → Branch: `main` → `/ (root)`.
2. En unos minutos estará disponible en:
   `https://starkprivacy.github.io/privacidad-news/`

También puedes abrir `index.html` localmente.
